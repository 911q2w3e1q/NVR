# 模型目录

仓库默认不含任何模型（版权原因）。

App 启动时会扫描这里（含 `models/` 子目录）以及手机上的
`Android/data/com.nvr.app/files/models/`，自动加载找到的第一个模型。

把你自己有权使用的 `.mesh` / `.glb` / `.vrm` 模型文件放进本目录或手机那个目录即可，
文件名随意。也可以通过 App 右下角「导入模型」按钮选择文件。

- `.mesh` / `.nvr2`：本项目私有 NVR2 格式，读取最快。
- `.glb` / `.vrm`：标准 glTF 2.0 二进制（VRM 是带扩展的 GLB），直接实时解析，拿来即用；
  模型较重时 App 会询问是否烘焙成缓存，确认后自动生成同名 `.nvr2` 并优先加载。

模型格式与两级加载机制详见仓库根目录 README 的「模型格式与两级加载」一节。
